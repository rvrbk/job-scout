# Location data

`countries.json` and `cities.json` are generated by `php artisan locations:build` from the
[GeoNames](https://www.geonames.org) dump (`cities15000` and `countryInfo`), which is licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). `LocationMatcher` uses them to tell which country a
job posting's location is in. Rebuild when you want fresher data.
